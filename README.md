# Photo Gallery

Click a thumbnail to feature it, or click the featured image for a fullscreen view.

![Screenshot](./assets/photo-gallery-web.png)

**Live demo:** [hunafazaky.github.io/photo-gallery](https://hunafazaky.github.io/photo-gallery)

## Features

- Featured image swaps with a short fade when a thumbnail is selected
- Keyboard navigation: arrow keys move between thumbnails; Enter/Space selects
- Fullscreen lightbox view — Escape to close, arrow keys to browse while open
- Image data (source, alt text, caption) lives in its own file, separate from the app logic

## Run Locally

Just open `index.html` in your browser — no install, no build step.
